# Aqara Open Lab · Care Platform Demo

**비접촉 생활 모니터링 플랫폼** 디자인 시안입니다.
어르신 거주 시설에 Aqara IoT 디바이스를 설치하여 **고독사 예방 · 활동 패턴 모니터링 · 가족 알림** 을 통합 제공하는 솔루션 미리보기.

🔗 **Live Demo**: https://haedo-doo.github.io/aqara-open-lab-demo/

---

## 📺 포함된 화면

| 화면 | 설명 |
|---|---|
| **대시보드 (바둑판 뷰)** | 호실별 상태를 한눈에 — 정상 · 이상 징후 (점멸) · 저전력 · 오프라인 |
| **방 상세 페이지** | 디바이스별 활동 로그, 알림 ON/OFF 토글, 임계치 커스터마이즈, 24h 활동 타임라인 |
| **Aqara 연결 설정** | 보안 정책 반영: AccessToken 평문 노출 없음, OAuth2 / 이메일 인증코드 두 방식만 지원 |
| **가족용 모바일 뷰** | SMS OTP 로그인 가족이 지정된 방만 조회, KakaoTalk 알림톡 수신 |

---

## 🚀 사용 방법

데모 사이트 상단 또는 각 카드를 눌러 화면 간 이동. 반응형 — 데스크톱, 태블릿, 모바일 모두 지원. 다크모드 토글 포함.
